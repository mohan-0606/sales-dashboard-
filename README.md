#📊 Sales Dashboard Analysis

##📌 Project Overview

This project focuses on analyzing sales data and creating an interactive Sales Dashboard to track business performance, identify sales trends, and generate meaningful insights.

🎯 Objectives

• Analyze overall sales performance.
• Track total revenue and profit.
• Identify top-performing products.
• Analyze monthly and yearly sales trends.
• Understand customer and regional performance.

🛠️ Tools & Technologies

• Microsoft Excel
• Pivot Tables
• Pivot Charts
• Slicers
• Data Cleaning
• Data Visualization

📈 Key Features

• Total Sales KPI
• Total Profit KPI
• Sales by Region
• Monthly Sales Analysis
• Product-wise Sales Performance
• Interactive Filters and Slicers
